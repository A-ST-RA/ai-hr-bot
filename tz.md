# Создание бота принимающего вопрос, анализирующий его в LLM и отдающего ответ

Цель: Создать конфигурируемого бота ответа на сообщения из базы данных, с обработкой запросов по средствам ИИ, который можно будет простым способом менять с одного провайдера сообщений на другой

## ТЗ

Есть интерфейс `BotApiService` который определяет базовый сервис отправки сообщений и создания веб хука
Пока есть только одна реализация `AvitoApiService`

Давай остановимся пока на avito
На Avito приходит вопрос о вакансии от человека, например ```Входит ли питание и проживание в оплату труда```

Этот вопрос приходит на наш бекенд по средствам WebHook, у нас в базе будет список вопрос/ответ (находится в проекте по этому пути src/api/question), отправляется список вопросов и наш вопрос в нейросеть, она должна вернуть, какой по вхождениям вопрос подходит на пользовательский и возвращает его

Далее на нашем бекенде мы фетчим данный вопрос(уже из нашей базы по клюучу) и отдаем ответ пользователю, если LLM не смогла определить, что это за вопрос, то возвращать шаблонный ответ по ключу `default`
